# Contributor Covenant Code of Conduct

Our project follows the Contributor Covenant code of conduct to support an open and welcoming community.

The short version: Be kind and respectful. If you run into problems or see concerning behaviour, please open an issue or contact the maintainers.

Full text: [Contributor Covenant v2.0](https://www.contributor-covenant.org/version/2/0/code_of_conduct/)
